# 🌾 Agroforte - Inovação e Sustentabilidade no Campo

## 🏷️ #agrinho2026

### 🎯 Objetivo do Projeto
O projeto **Agroforte** é uma plataforma web informativa e interativa desenvolvida para o Concurso Agrinho 2026. O objetivo principal é conscientizar alunos, produtores rurais e a comunidade sobre a importância da agricultura forte e sustentável, demonstrando como a fusão entre tecnologia moderna (IoT, automação) e práticas conservacionistas pode aumentar a produtividade e proteger os recursos naturais.

### 💡 Justificativa
A produção de alimentos enfrenta desafios crescentes devido às mudanças climáticas e à escassez de recursos. Apresentar o conceito de "Agroforte" por meio de ferramentas digitais interativas ajuda a aproximar a nova geração da realidade tecnológica do campo, provando que a tecnologia e a preservação caminham juntas para o sustento do planeta.

---

### 🚀 Tecnologias Utilizadas
- **HTML5:** Estruturação semântica do conteúdo da página.
- **CSS3:** Estilização customizada, uso de Flexbox para layouts fluidos e Media Queries para total responsividade (Mobile First).
- **JavaScript (Vanilla):** Manipulação dinâmica do DOM, controle de acessibilidade (modo escuro e tamanho de fonte) e lógica do simulador de consumo.
- **Canva / Paint:** Utilizados para a criação e customização da identidade visual e mídias próprias (se aplicável).

---

### 🛠️ Detalhes de Implementação e Funcionalidades (Rubrica)

1. **Complexidade do Código:**
   - O JavaScript captura dados inseridos pelo usuário, armazena em variáveis e atualiza o DOM em tempo real (ex: Saudação personalizada e cálculo do simulador).
   - O HTML usa tags limpas e acessíveis como `<button>`, `<input>` e tags estruturais estruturadas.
   - O CSS faz uso extensivo de variáveis `:root` permitindo a troca dinâmica de temas de forma limpa.

2. **Usabilidade:**
   - **Responsividade:** O site se adapta dinamicamente para smartphones, tablets e desktops via breakpoints CSS.
   - **Acessibilidade:** Inclusão de botões funcionais para aumentar/diminuir o tamanho da fonte e alternar para Modo Escuro, melhorando a experiência de leitura de usuários com limitações visuais.

3. **Organização de Mídias:**
   - Todos os recursos visuais do projeto encontram-se isolados na pasta `/assets/img/`.
